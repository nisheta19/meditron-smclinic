# Неизменённые синтетические эталоны v8

280 авторских текстов: пять последовательных наборов по 48 документов и последний
набор из 40. Каждый содержит восемь типов исследований, несколько находок,
сложные сочетания признаков и отрицательные случаи. В `round6` на каждый тип
приходится четыре составных положительных случая и один отрицательный.
Все тексты вымышлены, реальных документов или пациентов здесь нет.

Текст и ожидаемые код/атрибуты зафиксированы до первого запуска соответствующего
набора. Проверено отсутствие одинаковых текстов между наборами и прежними 232
синтетическими примерами, в том числе после удаления чисел, пробелов и пунктуации.
Это не гарантирует независимость формулировок: автор эталонов и исправлений один.
После первого анализа набор становится регрессионным. Повторный высокий результат
на нём нельзя представлять как результат на новых данных.

Оценщик создаёт настоящие DOCX и запускает обычный `process_event`; сохранённые
ответы не используются рабочим ML. Словарь и медицинские пороги не изменены.
Полные результаты всех первых прогонов, текущая версия и ограничения:
[отчёт](../../../docs/ml-generalization-v8.md),
[метрики](../../../docs/ml-generalization-v8.metrics.json).

## Повторить проверку

Из каталога `C:\hackaton\final\ml`:

```powershell
.\.venv\Scripts\python.exe -m app.generalization --gold eval/v8/round6-gold.json --output ../.local/v8-round6-check
```

Создаются девять вариантов оформления, `predictions.json`, `metrics.json` и общий
`summary.json`. Варианты оформления — те же 40 текстов, не новые независимые случаи.
Без параметров действует строгий порог F1 ≥95% и отсутствие ложных находок
в отрицательных случаях. Для v8 на этом наборе ожидается код выхода 1: F1 ниже
95%, при заглавных буквах остаётся одна ложная находка. Настройки по умолчанию
сохранены. Пользовательский критерий остановки этой доработки — F1 >90%.

Только исходное оформление с порогом 90% и прежней проверкой нулевых ложных находок:

```powershell
.\.venv\Scripts\python.exe -m app.generalization --gold eval/v8/round6-gold.json --output ../.local/v8-round6-original --variants original --min-f1 0.90
```

Для остальных наборов меняется только имя `roundN-gold.json`. Итоговая v8 уже
содержит исправления по ошибкам первых пяти наборов; это будет регрессионный прогон.

## Известный дефект разметки

В `round1`, `cycle1-012.docx`, ожидается `biradsSub: "B"` при кириллическом
`BI-RADS 4В`. Контракт использует нижний регистр, а действующий извлекатель
нормализует кириллическое `абв` в `abc`. Эталон содержит неоднозначную/невалидную
категорию. Исходный файл сохранён без исправления, случай не исключён из метрик.
Для будущей исправленной разметки нужна отдельная версия, а не перезапись истории.
