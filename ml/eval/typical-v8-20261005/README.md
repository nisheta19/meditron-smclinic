# Новые типовые синтетические протоколы, 05.10.2026

96 вымышленных текстов в `gold.json`: по 12 для каждого из восьми типов
исследования, из них 9 с находками и 3 без находок. Всего 81 находка,
286 размеченных атрибутов и 29 из 48 активных кодов. Тексты составлены ассистентом;
«типовые» описывает замысел набора, а не подтверждённую частоту случаев в клинике.

Эталон зафиксирован перед первым вызовом модели. SHA-256:
`247e20ab445fb52630a7ebddfe1c36c8b453c5eb658d22f98b8986bb9dda18bf`.
Среди 512 уникальных прежних текстов совпадений нет, в том числе после удаления
чисел, пробелов и пунктуации. Это не доказывает независимость формулировок.
Код модели и YAML не менялись; после просмотра результатов набор стал регрессионным.

Исходный строгий F1 — **77,30%**, с переносами строк — **76,07%**.
Оцениваются код и все размеченные атрибуты; дополнительные атрибуты не оцениваются.
Находки учитываются до применения порогов маршрутизации backend.

После запуска обнаружена ошибка разметки `typical-006`: оборот «по типу АИТ»
требует `uncertain=true` по `ml.uncertaintyCues`. Исходный `gold.json` сохранён
неизменным. Отдельный ретроспективный пересчёт с этой поправкой даёт **78,53%**.
Это исправление эталона, не улучшение модели. Если дополнительно приравнять
отсутствующий булев атрибут к `false`, как при применении правил backend,
получается **82,21%**; это другая семантика сравнения, а не строгий F1.
