# Четыре новых сложных набора для разработки v9

По 48 вымышленных протоколов в каждом `roundN-gold.json`, восемь типов
исследований, в каждом типе пять положительных и один отрицательный случай.
Несколько образований, стороны и категории, анамнез, отрицания, нормальные
структуры и числовые отвлекающие признаки проверяют связывание фактов.
Тексты и ответы зафиксированы до первого запуска каждого набора.
Эталоны не изменять под результат модели.

| Первый прогон | F1 полной находки | Диапазон по 9 вариантам |
|---|---:|---:|
| round1 | 88,89% | 88,89% |
| round2 | 87,67% | 86,30–87,67% |
| round3 | 88,89% | 88,89% |
| round4 | **94,44%** | **94,44%** |

Четвёртый набор: 72 находки, 301 размеченный атрибут, 30 кодов справочника.
Есть одна ложная находка среди восьми отрицательных документов. Общий порог
>90% достигнут, но по почкам и простате F1 ниже 90%; стандартный порог 95%
с нулём ложных находок в норме не достигнут.
Это синтетическая инженерная оценка без независимой клинической разметки.
[Полный отчёт и ограничения](../../../docs/ml-generalization-v9.md).

Команды из `final/ml`:

```powershell
# Повторяет численный результат; это уже регрессия, а не новые данные.
.\.venv\Scripts\python.exe eval/v9/run_cycle.py --gold eval/v9/round4-gold.json --output ../.local/v9-round4-reproduction

# Стандартный строгий порог 95% / ноль ложных находок в норме: код выхода 1.
.\.venv\Scripts\python.exe -m app.generalization --gold eval/v9/round4-gold.json --output ../.local/v9-standard-gate
```

`run_cycle.py` отказывается перезаписывать каталог результата; проверяет
справочник, уникальность текстов без чисел и пунктуации, перед анализом сохраняет
хеши и архив исходников, запускает девять DOCX-вариантов и сверяет счётчики
вторым алгоритмом сопоставления. Код выхода 0 означает F1 **строго больше 90%**
во всех вариантах без сбоев обработки. Отсутствие ложных находок в норме
не входит в этот пользовательский критерий; их количество сохраняется отдельно.
Оценщик `app.generalization` и его стандартные пороги не изменялись.

Для следующей новой проверки сначала подготовьте отдельный эталон без просмотра
предсказаний, затем используйте новый каталог вывода. Повторная оценка известных
файлов не доказывает обобщение. Исторические первые прогоны относятся к разным
версиям правил; актуальная v9 на round1–3 даёт 100% в регрессионной проверке.

Первоисточники первых результатов на этой машине:
`.local/ml-v9-cycles/round1` … `round4`: `before.json`, `source.zip`,
`first-pass.json`, `evaluation/<variant>/predictions.json` и `metrics.json`.
