# Новый стресс-тест неизменённой v9

96 синтетических протоколов, восемь типов исследований, по девять положительных
и три отрицательных случая в каждом типе. В эталоне 113 находок и 439 атрибутов,
44 из 48 активных кодов того же справочника. `gold.json` зафиксирован до первого
анализа и после просмотра предсказаний не изменялся.

Первый результат: **строгий F1 67,86%**, по девяти вариантам оформления
**66,07–67,86%**. F1 кода со стороной/локализацией — 93,75%; ложные находки
в 2/24 отрицательных документов. Порог >90% не пройден. Исправлений модели
в рамках этой проверки не было.

[метрики и хеши](../../../docs/ml-stress-v9-20261005.metrics.json),

Из `final/ml`, в новый каталог результата:

```powershell
.\.venv\Scripts\python.exe eval/v9/run_cycle.py --gold eval/stress-v9-20261005/gold.json --output ../.local/stress-v9-reproduction
```

Команда возвращает код 1 из-за F1 ниже порога, а не из-за сбоя обработки.
`run_cycle.py` сохраняет хеши/архив до запуска и проверяет их после; исходные
результаты находятся в `.local/ml-v9-stress-20261005/first-run`.
Для обычного оценщика с порогом 95% и нулём находок в норме:

```powershell
.\.venv\Scripts\python.exe -m app.generalization --gold eval/stress-v9-20261005/gold.json --output ../.local/stress-v9-standard
```

Это повторит результат известного набора, а не даст новую оценку обобщения.
Для следующего стресс-теста нужен отдельный эталон с ответами до предсказаний.
Синтетическая авторская разметка не заменяет независимую клиническую валидацию.
