## Вывод

В архиве есть полезный React-интерфейс: списки, карточка пациента, цитаты,
ручная проверка находок, справочник и отдельное демо маршрутов. Для прямого
слияния с текущим проектом архив не подходил: его общие настройки соответствовали
более старой версии backend + ML. Импортирован frontend, необходимые исправления

## Исправленные проблемы

| В архиве | В итоговом проекте |

| По умолчанию вымышленные данные | Настоящий API; демо только по явному флагу |
| Compose отключал ML и терял проверки готовности | Четыре сервиса, healthcheck, localhost, прежние тома |
| `vite preview` и неправильный localhost backend в контейнере | Production-сборка за nginx; `/api/` → `backend:8080` |

| Подстановка вымышленных маршрутов, сроков, просрочек | Показ специалиста и срока, рассчитанных backend |

| Действия на FAILED, аннулированных и старых версиях | Изменения доступны только для успешно обработанной действующей версии |

## Как сохранить изменения

Не заменяйте текущий Compose и backend файлами из ZIP. Подготовленные изменения
можно закоммитить в отдельную ветку от текущего `main`, отправить её и создать PR
с базой `main`. Исходную ветку frontend повторно сливать поверх этих правок
не требуется. ZIP не содержит историю Git, поэтому заранее проверить настоящие
merge-конфликты удалённой ветки по нему невозможно.
