# ML v2.1 — ревью, сверка архива и метрики

Исторический отчёт об извлечении v6 до интеграции с новым backend.
Упомянутые здесь приватные пакеты/разметка остаются в исходной рабочей папке
`C:/hackaton/src/meditron-smclinic-main/ml/.local/` и не скопированы в `final/`.
Текущий результат интеграции и факт отправки в локальный backend описаны в
[отчёте проверки](verification.md).

Дата: 2026-10-04. Модель: `dict-v2.1-extractor-6`, словарь `dict-v2.1`.
Основа — новый архив `ml.zip` (латинское имя), не предыдущий `мл.zip`.
Исходные протоколы, Excel, YAML и synthetic-gold.json не изменялись.

## Результат

Сервис принимает DOCX через FastAPI, извлекает текст, разделы, находки и
атрибуты, проверяет точность координат цитат и контракт, сохраняет результат
в SQLite, затем отправляет backend. Повторы сохраняют resultId и весь payload.
Пакет `ml/.local/backend-release-v6/`: 89 DONE, 166 находок, не отправлен.
ML не исполняет медицинские правила маршрутов.

## Что изменено

- Новый справочник: 48 активных кодов; сохраняются корневые ml/flags/version.
  Отключённые коды исключаются. GET запрашивает полный объект через full=true.
- Новый контракт: dictionaryVersion, flags протокола и находок, новые атрибуты.
  Backend-флаги отклоняются валидатором; отсутствующее значение не заменяется null/0.
- Находки ниже порога передаются. BI-RADS 1 и физиологическое жёлтое тело
  переводятся в notTriggered NORMAL; BI-RADS 2 остаётся находкой.
- Описательная находка не теряется из-за нормального/отрицающего заключения.
  Добавляются DISCREPANCY, INCOMPLETE и другие ML-флаги.
- Разделены поверхностный, глубокий и перенесённый тромбоз; одновременный
  глубокий тромбоз не теряется из-за поверхностного. Отрицание признака
  ущемления/непроходимости не отменяет саму грыжу.
- Уточнены стороны, FIGO, Kwak, единицы, категории, гранулярность находок,
  PCOM, контекст менопаузы/цикла, шейка матки, остаточная моча и измерения.
  Год из даты не превращается в день цикла; ошибочная дата не обрушает анализ.
- Новые коды работают через синонимы, простые новые атрибуты — через
  attributeExtractors. Действующие специализированные профили покрывают
  известные формулировки; свободный текст extraction/notThis не является программой.
- HTTP перенесён на FastAPI; демонстрация использует настоящий TCP/HTTP
  через uvicorn. Логи содержат идентификаторы, коды, время и статус доставки,
  без клинического текста и имён.
- Оценщик учитывает FAILED как пропуски, сопоставляет находки один к одному,
  не штрафует разрешённые optional и не даёт им скрывать дубликат.

## Метрики

Строгое совпадение полной находки: код и все **размеченные** атрибуты.
Неразмеченные дополнительные атрибуты не оцениваются. Неправильный атрибут
даёт FP и FN. Сравнение кодов учитывает сторону/локализацию, если они размечены.

| Набор | Документов | Precision полной находки | Recall полной находки | F1 полной находки | F1 кодов со стороной/локализацией |
|---|---:|---:|---:|---:|---:|
| Настроечные реальные по Excel | 61 | 87,61% | 97,06% | 92,09% | 94,88% |
| Помеченные «отложенными» в Excel | 28 | 83,02% | 93,62% | 88,00% | 94,00% |
| Синтетические | 33 | 97,92% | 100% | 98,95% | 98,95% |
| **Итого** | **122** | **88,79%** | **96,94%** | **92,68%** | **95,61%** |

Все реальные вместе: F1 полной находки **90,79%** (TP 143, FP 23, FN 6).
Синтетика: TP 47, FP 1, FN 0. Общая точность размеченных атрибутов:
402/408 = **98,53%**. Recall кодов со стороной/локализацией — 196/196, **100%**.
Срочные/экстренные находки синтетики — **16/16**; в реальной машинной
транскрипции уровни маршрутов не размечены, поэтому этот recall там не оценён.
Обязательные notTriggered — **26/26**; запрещённых срабатываний ловушек — **0**.
DISCREPANCY: реальные 26/28, синтетика 4/4, всего **30/32**.
Отсутствуют два флага из строки Excel о несоответствии рекомендаций — это
не то же самое, что противоречие описания заключению, которое проверяет ML.

Среднее время полного process_event в последнем локальном прогоне:
реальные 40 мс (максимум 85 мс), синтетические 37 мс (максимум 66 мс).
Это обработка небольших DOCX без сети и ожидания очереди, не нагрузочный тест.

## Ограничения эталона и остаточные расхождения

Синтетический gold используется побайтно исходный. Excel содержит свободный
текст; его перевели в `ml/.local/v21/real-gold.json` с sourceRow:
89 протоколов, 149 находок. Нормализация отдельно отмечена: округлённые размеры
заменены исходными 14,7 / 64,77 / 36,11 / 54,27; неоднозначные размеры кист
уточнены по документу (справа 23, слева 30); строка 139 с bilateral Br2
соответствует одному факту side=both. Оригинальный Excel сохранён.
Поэтому это строгий расчёт по документированной транскрипции Excel,
а не побуквенное сравнение с произвольными ячейками.

Шесть несовпадений атрибутов оставлены в основном расчёте:

| Документ | Эталон | Исходный текст / поведение извлекателя |
|---|---|---|
| Нижние конечности (2) | maxStenosisPct=0 | «Нестенозирующий» без процента; 0 не выдумывается |
| ОМТ (11) | fromMeasurement=true | Неоднородный эндометрий назван в заключении; факт не только из измерения |
| ОМТ (21) | sizeMm=22 | Размер 22×23; по правилу максимума возвращается 23. FIGO 6/5 помечены расхождением |
| ЖП (21) | atypical=false | Нет достаточного явного описания для обязательного false; атрибут пропущен |
| ЖП (7) | uncertain=true | В заключении сладж утверждается, без маркера предположения |
| Молочная железа (2), слева | sizeMm=4 | Размер 4 мм описан справа; на левую сторону не переносится |

Ещё 17 дополнительных реальных фактов не размечены в Excel: наботовы кисты,
PCOM по измерениям, сниженный резерв по названным признакам, тонкий эндометрий
при менопаузе, малое количество свободной жидкости, сладж и остаточная моча 7 мл.
Они сохранены по правилам v2.1 и считаются FP в основном расчёте. Подробная
сверка по документам — `ml/.local/v21/discrepancies.json`.
Единственный синтетический FP: измерение эндометрия 3 мм в менопаузе,
которое YAML требует вернуть, но synthetic-gold для протокола 15 не содержит.

В архиве по-прежнему есть противоречия между правилами и ожидаемыми ответами.
Для 100% F1 пришлось бы скрыть эти факты или выдумать атрибуты. Эталон ради
такой цифры не менялся; отдельный «исправленный gold» не выдаётся за независимую оценку.
F1 88% в помеченной отложенной группе остаётся видимым ограничением.

Все 89 реальных документов уже использовались в предыдущих версиях. Метка
«отложен» в новом Excel не делает их независимой выборкой. В требованиях список
отложенных документов содержит 25, а фактические метки Excel — 28; расчёт следует Excel.
Старые 98,46% по v1 получены на другом контракте и разметке, сравнивать напрямую нельзя.
Неразмеченные атрибуты и произвольные неизвестные диагнозы не покрыты этой оценкой:
UNRECOGNIZED_ABNORMALITY распознаёт словарные формулировки, универсального
понимания любой новой формулировки в локальном извлекателе нет.
