## Использование

Откройте http://127.0.0.1:3000 . Логин **123**, пароль **123**.
Нажмите на профиль врача внизу боковой панели, затем **«Выйти»**.
Сервер завершает сессию, интерфейс показывает экран авторизации. Повторный вход
возможен сразу. Перезагрузка сохраняет действующий вход, но не восстанавливает
завершённую сессию. Ссылка на текущую страницу сохраняется для следующего входа.

## Что подключено

- `Login` и `DoctorMenu` используют предоставленные изображения, шрифты и стили.
- `GET /api/auth/me` проверяет сессию; логин и выход работают через API.
- `AUTH_REQUIRED=true` по умолчанию закрывает API пациентов, находок и протоколов
  без сессии; изменяющие запросы требуют CSRF. Токен обновляется после входа.
- Пароль и идентификатор сессии не записываются в localStorage. Cookie — HttpOnly.
- Ответ 401 от API возвращает экран входа. Ошибка сети при выходе не выдаётся
  за успешное завершение сессии: можно повторить действие.
- Скрипты отправки DOCX, создания вымышленных пациентов и проверки системы
  авторизуются автоматически через общий `scripts/backend_session.py`.

Единственный аккаунт задают `AUTH_LOGIN` / `AUTH_PASSWORD`; регистрации новых
аккаунтов нет. Старый `.env` с `AUTH_REQUIRED=false` нужно переключить на `true`.
Машинные интеграционные API, словарь и health сохраняют прежний доступ для ML.
Это авторизация кабинета врача для локального хакатона, а не завершённая схема
защиты всех сервисов для публичного развёртывания.

Явный автономный режим `?mock=1` и документация API остаются доступными без сессии.
Дашборд сохраняет статичные показатели, но в рабочем режиме проверяет вход.
