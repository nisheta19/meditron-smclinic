# ML-сервис

Зона Даши. Предлагаемый вариант: Python + FastAPI, порт **8000**.

## Как ML встроен в систему

```
МИС (на демо — эмулятор) ──файл протокола + метаданные──▶ ML
ML ──результат: пациент, протокол, находки──▶ бэкенд  POST /api/integration/ml/results
```

- **Бэкенд в ML не обращается.** ML сам получает файл протокола от МИС, извлекает текст,
  заключение и находки и отправляет результат в бэкенд.
- Адрес бэкенда для ML — переменная окружения `BACKEND_URL`
  (локально `http://localhost:8080`, в Docker `http://backend:8080`).
- Формат входа от МИС и выхода в бэкенд — документ «Требования к ML-сервису»
  (ссылка в [`docs/api-contract.md`](../docs/api-contract.md)).
- Коды находок, синонимы, атрибуты и ловушки — словарь
  [`backend/src/main/resources/dictionary/findings-dictionary.yaml`](../backend/src/main/resources/dictionary/findings-dictionary.yaml).
  Тот же словарь отдаёт бэкенд: `GET /api/dictionary/findings`.
- **Главный документ для ML (и для ИИ-ассистента, который пишет код сервиса):**
  [`docs/ML-REQUIREMENTS.md`](../docs/ML-REQUIREMENTS.md) — контракт, флаги, правила извлечения,
  разметка, синтетика, отложенные протоколы и метрики. Словарь — версия `dict-v2.1`.
- Эталонные ответы по 33 синтетическим протоколам — [`ml/eval/synthetic-gold.json`](eval/synthetic-gold.json) (сами .docx не в Git).

## Данные

Выданные протоколы в Git не кладём: локально в `data/raw/` (папка в `.gitignore`).
Большие файлы моделей тоже не коммитим.

Чтобы подключить сервис в `docker-compose.yml`, добавь сюда `Dockerfile`
и раскомментируй блок `ml`.
