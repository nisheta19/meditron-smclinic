## Запуск

```bash
npm install
npm run dev        # http://localhost:5173, по умолчанию демо-режим
```

## Документация OpenAPI
[http://localhost:5173/open-api](http://localhost:5173/open-api)

## Демо-режим и backend

Переключение одним флагом (`.env.local`, образец в `.env.example`):

```bash
VITE_USE_MOCK=true                    # заглушки и демо-данные (по умолчанию)
VITE_USE_MOCK=false                   # реальный API
VITE_API_URL=http://localhost:8080    # адрес backend
```

## Экраны (по макету Figma)

- **Дашборд** — статичная демо-страница из макета: карта сети клиник, результативность уведомлений, «Доходят до конца», четыре показателя. Одинакова с заглушками и с реальным backend (флаг мока на неё не влияет); переключатели «Москва» и «За неделю / месяц / всё время» меняют демо-набор цифр.
- **Входящие, Находки, Картотека** — списки пациентов и находок с поиском, чипами и фильтрами. В «Находках» строки всегда можно отметить галочками и отправить уведомление, в том числе без мока; если backend ещё не принимает уведомления, в итоге отправки это указано.
- **Карточка пациента** — одна плашка: данные, протокол с подсветкой, находки («Орган / Находка / Статус» — уровень срочности), маршрут; справа за разделителем история приёмов. Закрывается круглым крестиком справа сверху. Заголовки — Manrope.
- **Словарь находок** — открывается по блоку врача внизу меню (в макете пункт «Настройки» убран из меню).
- **/open-api** — документация API, без ссылок из интерфейса.

## Структура

```
docs/
  openapi.yaml               контракт API
  ml-results/                демо-данные в формате MlResult
src/
  api/client.js              HTTP-клиент, флаг USE_MOCK
  api/mock/server.js         заглушка backend
  api/mock/seed.js           словарь, шаблоны маршрутов, сценарии демо
  lib/format.js              подписи enum, форматирование дат
  lib/hooks.js               загрузка, сортировка, выделение, роутинг, тосты
  lib/enrich.js              догрузка данных для строк списков
  components/Icons.jsx       иконки и логотип из макета (JSX)
  components/kit.jsx         элементы макета: поиск, чипы, чекбокс, список карточек
  components/Dropdown.jsx    выпадающий список
  components/                диалоги, текст протокола, карточки находки и маршрута
  pages/                     Дашборд, Находки, Входящие/Картотека, Карточка, Словарь, ApiDocs
  components/dashboard/art.js  векторы дашборда из макета (точечная карта, волна)
scripts/build-static.mjs     сборка в один HTML
```
