# Вымышленные данные автономного демо

Эти файлы обслуживают только `?mock=1` и статическую презентацию интерфейса.
Они используют прежнюю упрощённую схему и условный словарь из `src/api/mock/seed.js`.
Не передавайте их в рабочий backend и не используйте как эталон для ML.

- `demo.json`: 17 синтетических сообщений для демонстрации состояний интерфейса.
- `demo-queue.json`: 3 синтетических сообщения для кнопки поступления протокола.
- `samples.json`: пустой массив. Семь текстов исходных медицинских протоколов
  из полученного архива исключены из репозитория и сборки.

Совместимые с текущей интеграцией примеры создаёт `tests/frontend_fixtures.py`:
настоящие вымышленные DOCX проходят через backend и текущий ML. Сквозные тесты
`tests/integration.py` проверяют контракт и серверные правила.
